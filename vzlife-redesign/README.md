# Ваше Здоровье — редизайн (макет)

Дизайн-концепт редизайна vzlife.ru. 4 страницы, готовые для передачи вёрстальщику.

## Как посмотреть сайт «вживую» после загрузки на GitHub

Просто загрузить файлы в репозиторий — недостаточно, GitHub не открывает `.html` как страницу сам по себе.
Нужно включить **GitHub Pages** (бесплатно, 2 минуты):

1. Создайте новый репозиторий на GitHub (например, `vzlife-redesign`)
2. Загрузите в него все файлы из этой папки (перетащить в веб-интерфейсе — тоже подходит)
3. Зайдите в репозитории в **Settings → Pages**
4. В разделе **Build and deployment → Source** выберите **Deploy from a branch**
5. **Branch** — выберите `main` (или `master`), папка — `/ (root)`, нажмите **Save**
6. Подождите 1–2 минуты — GitHub покажет ссылку вида:
   `https://ваш-логин.github.io/vzlife-redesign/`
7. Открывайте — это и есть главная страница (`index.html` подхватывается автоматически)

Другие страницы будут доступны так:
- `.../catalog.html` — каталог
- `.../cart.html` — корзина
- `.../account.html` — личный кабинет

## Структура файлов

```
index.html      — главная страница
catalog.html    — каталог с фильтрами
cart.html       — корзина
account.html    — вход/регистрация + личный кабинет

styles.css      — общие стили (шапка, футер, кнопки, токены) — подключены везде
home.css        — стили только для index.html
catalog.css     — стили только для catalog.html
cart.css        — стили только для cart.html
account.css     — стили только для account.html
```

Все файлы должны лежать в одной папке — html-файлы ссылаются друг на друга и на общий `styles.css` относительными путями.
